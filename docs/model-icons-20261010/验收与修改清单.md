## 使用方式

后台 → 模型渠道 → 逻辑模型 → 编辑目标模型 → 上传自定义图标 → 应用修改。保存后刷新前端读取最新配置；“恢复默认图标”清除内置图标覆盖与自定义图片，恢复当前自动匹配规则。支持 PNG、JPG、WebP、SVG、ICO，单文件最大 300KB（沿用项目品牌图片资源契约）。图片先读取为编辑草稿，点击应用修改后随既有逻辑模型设置保存，不建立额外媒体或生成任务。

自定义图片优先显示；选择内置图标会清除自定义图片。自定义图标原样保留颜色、按图标槽等比显示，加载失败时回退内置/默认图标。Canvas、图片/视频工作台的共享模型选择器以及创作 Agent 和紧凑 Agent 模型设置均使用该配置。
