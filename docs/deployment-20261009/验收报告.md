## 部署与未验收范围

上传压缩包或整个目录到已安装 Docker Engine/Compose v2 的 Linux amd64 服务器。压缩包解压后进入 `本次修改需上传文件_20261009`，核对 SHA256SUMS，再运行 `bash 一键部署.sh`。继续使用服务器已有 .env 与账号、任务和媒体持久卷；首次部署需要配置独立外部 PostgreSQL 的 DATABASE_URL。默认 external 端口 8866，已有 .env 的端口继续保留；显式改端口用 `DREAMYO_PORT=8866 bash 一键部署.sh`。
