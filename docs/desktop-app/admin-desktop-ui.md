# Dreamyo 管理员本地版桌面界面方案（2026-09-22）

## 目标与参考

参考用户提供的 MiniMax Design 十张截图提炼**窗口内统一的应用导航、项目库、持久侧栏、画布工作区、设置入口和折叠态**。仅借鉴结构和任务流；不复制该产品的品牌、文案、图标、素材、精确尺寸或颜色。Dreamyo 复用现有 Web 的紫色主色、蓝青渐变、月球背景和现有图形 Logo。原 Web 站点的页面与运营导航保持原样，管理员本地版按独立软件组织。

## 工作区信息架构

| 一级入口 | 内容与行为 | 数据来源 |
| --- | --- | --- |
| 开始创作 | 打开有项目名称的创建弹窗，确定后进入同一个 Canvas 实体 | 本机项目库 |
| 项目库 | 标题、说明、新建/导入、搜索、本地项目列表与真实空态 | 已持久化 Canvas 项目 |
| 模型与渠道 | 既有渠道目录及 GeminiAIStudio、Dola、GeminiTools、GPTAPI、即梦等配置 | 本机数据库与 Provider |
| 技能与连接器 | 现有 Agent Skills | 本机配置 |
| 最近项目 | 由已经读取的项目摘要派生，点击直达对应画布，不插入假项目 | Canvas store |
| 设置 | 在右侧工作区提供模型与渠道、网络代理、运行记录、应用设置四类平面导航及真实子页 | 沿用后台服务 |
| 外观 | 侧栏底部选择浅色或深色；画布、项目库、设置和 Ant Design 控件同步切换并保存偏好 | Electron 本机应用目录 |

侧栏在项目库、画布、设置之间持续可见，可以折叠为仅图标；常用操作保持无缩进。项目库保留 Web 已有的 `cosmic-night-bg.png` / `cosmic-light-bg.png` 月球背景，但不沿用网站侧栏或占据首张项目位的大型“新建项目”卡片。设置不是 Web 后台树状菜单，也不混入用户、套餐、支付和公告等云运营项目。复杂 Provider 表单继续复用已有逻辑，避免视觉重做时改变任务与密钥语义。

## 窗口与主题

macOS 使用 `hiddenInset` 保留原生红黄绿窗口按钮，窗口左上保留拖动区，品牌与导航位于其下；Windows 用系统窗口控制覆盖层，右侧预留按钮空间，随主题切换颜色；Linux 暂留原生窗口框。可点击控件不属于拖动区。浅色底色 `#f5f7ff`，深色底色 `#080b14`，活动主色取 Web 的 `#6366f1`；侧栏、设置选中态和 Ant Design 控件协调使用该色，主按钮直接沿用 Web 的紫色渐变，悬停和焦点兼顾蓝青辅助色。月球背景直接引用 Web 的原资源，不在桌面包内复制素材。页面切换或重启不得将所选主题恢复为站点默认值。Web 主题仍沿用其既有独立配置。

## 实施映射

- 根 `AppProviders` 仅为管理员本地版的 `/canvas`、`/canvas/[id]`、`/admin` 增加共享桌面框架。Web 版仍渲染原布局。
- `DesktopAppShell` 负责本地侧栏、折叠、最近项目、导航和主题开关，不读取账户 Cookie、代理凭据或模型密钥。项目库负责新建弹窗与列表；Canvas 节点、右侧资产及 Provider 调用沿用现有组件。
- `/admin` 保留 `AdminDashboard` 的真实分区内容，在桌面分支把原 Web 折叠栏替换为平面分类和子页；只有分类切换意图触发目标分区预加载，URL 保留 `section`，刷新恢复当前分区。
- 页面内的主题交互仍使用既有 Zustand store；Electron Main 将偏好保存到应用目录，在每次启动时提供给 Renderer，并同步 Windows 标题栏和窗口背景。桌面本地服务每次启动会更换端口，故不能以按来源隔离的 `localStorage` 作为跨重启唯一存储。IPC 只接受可信页面的 `light`/`dark` 输入。

## 当前电脑的模型配置

当前 Web 本地数据库的 14 个渠道、42 个逻辑模型、4 个默认模型及渠道密钥已通过桌面版管理员设置接口导入当前电脑的独立应用数据库，密钥在目标库使用桌面运行时密钥重新加密。模型配置不写入软件安装包，避免把 API 密钥分发给所有安装用户。重装但保留该电脑应用数据目录时配置继续存在；全新设备的凭据同步仍属于桌面应用的独立交付范围，不能把“当前电脑已配置”误称为“任意全新电脑自带凭据”。Dola 的 Cookie 账号池独立于模型目录，需要单独迁入并复核登录态；上游可用性以真实请求为准。

## 验收标准

1. macOS 未签名测试包打开项目库时，系统窗口按钮和左侧应用栏协调；创建项目需要名称，创建后进入该项目，刷新与重启仍能找到；搜索、导入、重命名、删除保留原有行为。折叠与恢复侧栏后工作区尺寸正确。
2. 打开真实画布时侧栏持续存在，画布可交互、节点与工具栏未被侧栏或系统按钮遮挡；从侧栏进入渠道/代理/设置，再返回原项目。设置禁用云经营项，Dola 与其他本地页仍可用。
3. 深色和浅色分别检查项目库、画布、设置、下拉菜单、弹窗；切换后页面与控件立即更新，重启保留。1440×960 和 1024×768 均无水平溢出，键盘焦点可见。
4. Web `/canvas` 与 `/admin` 保持原网站导航和主题设置。生产构建、相关与全量测试、Lint、类型检查和管理员应用实际打包烟测通过。
5. Windows 10/11 的原生按钮、缩放、标题栏覆盖层和浅深主题仍需在 Windows 实机安装包验收；macOS arm64 结果不能代替它。其余管理员版功能缺口另见 `status-audit-20260922.md`。
