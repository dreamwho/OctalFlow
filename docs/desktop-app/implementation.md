# Dreamyo 桌面化实施记录与验收清单

更新：2026-09-22。基线为 `5c50e9d`，远端 `main` 和 `backup/pre-desktop-20260922` 标签；完整 Git bundle 位于项目同级 `Octal-Canvas-backups/`。开发分支为 `codex/desktop-app-foundation`。

## 三种运行形态

| 形态 | 身份与账务 | 业务数据 | 上游配置与生成 |
| --- | --- | --- | --- |
| Web | 云端登录、积分、支付 | 云端 PostgreSQL / OSS | 云端配置；全部按 Web 规则计费 |
| 商用桌面 | 云端实时登录、积分、支付 | Canvas/素材/短剧本地优先，购买容量后可备份 | 本地代理及五种 Provider 本地配置与执行不扣积分；其余模型走云端并实时扣费 |
| 管理员本地 | 无登录/积分/支付 | 仅本地，独立目录 | 所有渠道在本地配置，网络模型仍需自行提供上游凭据；本地调用不扣积分 |

Web 对外接口与后台仍保留全部功能。桌面版不能通过更改 URL、请求头或浏览器 JS 来改动版本：安装包内 `edition.json` 固定版型，进程仅绑定 `127.0.0.1`，随机运行令牌仅由 Electron 发给本地源。管理员本地版借用现有的权限、Session、文件存储逻辑，在独立数据目录自动建立本地管理员。此身份不得同步到商业云端。两个桌面版使用不同 appId/userData，Cookie、代理凭据、素材与项目不会随安装包分发。

## 已落地的第一阶段

- Electron 主进程、preload 白名单 IPC、沙箱隔离、单实例、防跨源导航、外部 HTTPS 链接分离、独立运行数据目录。
- 管理员免登录引导：桌面令牌 + loopback 双条件，生成普通 HttpOnly Session；Web 环境返回 403。
- 管理员本地版隐藏商业运营分区、账务入口、站点初始化向导和账号/邮件系统设置，并在代理层拒绝云端商业路由；本地生成计价为 0，仍保留任务/幂等流水契约。
- Next standalone、Worker 与三个 Provider 的桌面端口和账号目录隔离；桌面不执行固定端口残留进程清理。
- 打包白名单与平台 Sidecar 预检：未提供目标架构的冻结可执行文件和 Camoufox 浏览器时拒绝打包，防止发出需要 Python/Docker 的假完整安装包。
- 桌面 Mihomo 启动编排与独立私有订阅目录已接入，四种 Provider 代理出口和控制器只绑定 loopback；预检增加 Mihomo、FFmpeg/FFprobe、即梦 CLI、视频深度推理程序与固定模型文件。当前 macOS arm64 已准备并分别验证这些运行时文件，视频深度以本地固定模型完成离线推理，FFmpeg/FFprobe 以实际帧编码和探测验证，`prepare-runtime` 在本机通过；其他目标架构仍未构建。
- Dola Provider 已在当前 macOS arm64 机器上用 PyInstaller 冻结为独立程序，空账号健康检查正常且未授权的模型目录返回 401；Mihomo 官方 arm64 程序用私有生成配置实测可启动，控制器未授权 401、正确密钥可读版本。这不等于已通过实际账号的完整生成，也不等于 Windows 或干净机验证。

macOS arm64 管理员版已有仅供本机验收的未签名 DMG/ZIP；仍未完成干净目标机器验收和商业分发签名/公证，Windows 安装包以及商用桌面版的云端身份/混合账务与跨设备同步也未完成。商用入口目前只显示开发状态，不允许创建本地测试账号，以免误当成云端登录。不要把第一阶段的 `runtime` 能力清单当成已实现云端同步的证据。

## 第二阶段：无依赖安装包

1. 对 macOS arm64、macOS x64 和 Windows x64 各自在目标系统构建 Next standalone 与 Sharp 原生库。不要跨架构复用构建结果。构建脚本只打包编译后的运行文件，严格排除 `.env*`、`.data`、Cookie、浏览器 Profile、备份、测试结果。
2. 将 Dola、GeminiAIStudio、GPTAPI 和独立 Gemini Camoufox launcher 分别冻结为可执行文件。`resources/sidecars/<platform>-<arch>/` 必须包含 `dola-api`、`geminiai`、`chatgpt-api`、`geminiai-browser`（Windows 加 `.exe`）及 `camoufox/` 完整浏览器目录、根目录 `version.json`，macOS 浏览器可执行文件旁另有同版本 `properties.json`。冻结时验证动态导入、模板/静态文件、证书、Playwright/Camoufox 包与浏览器匹配；输出 SHA-256 清单。生产进程只使用包内文件。
3. 对 GeminiTools OAuth 回调、即梦 CLI 固定版本、Mihomo 魔法/链式代理、FFmpeg/FFprobe 和视频深度推理建立同样的架构独立可执行文件及运行目录。包内缺少任何启用功能所需二进制时启动必须显示准确缺失项，不能静默回退系统 PATH。
4. 补齐签名与更新：macOS 签名/公证、Windows Authenticode/NSIS；签名更新清单、版本回退与本地数据兼容回归。首次安装和升级必须在一台没有 Node/Python/Docker 的干净虚拟机通过。

## 第三阶段：商用桌面云端身份与混合路由

- 云端提供单独的桌面设备授权（浏览器 OAuth/一次性授权码）。云端签发短时 access token 和设备绑定的 refresh token；本地系统钥匙串/Windows Credential Manager 保存刷新凭据。令牌不得进入 Canvas 项目文件、代理日志或备份。退出登录撤销设备令牌并删除本地凭据。
- 本地服务维护独立 `localUserId ↔ cloudUserId` 绑定；登录态必须由云端验证，不能将本地文件账号视为云端账号。多用户同机的数据目录按云端用户隔离。
- 云端模型请求直接提交云端 API，积分消费/幂等/退款由云端事务执行；本地代理、GeminiAIStudio、Dola、GeminiTools、GPTAPI、即梦 CLI 及其本地模型走本地 Provider，无积分消耗。模型目录合并时每条绑定带 `executionLocation: local|cloud`，任务创建时固定快照并落日志，禁止根据模型名猜测计费位置或运行中切换。
- Web 始终执行云端规则：即使同一用户在桌面配置过本地 Provider，浏览器访问网站仍用云端后台配置并消费积分。
- 云端调用需在线；离线时本地项目编辑与已就绪素材浏览可用，云端登录、支付、余额确认、云端模型调用显示明确离线状态，不假记扣费。重连后只重试有稳定幂等键且云端尚未受理的请求。

验收：同一个云端账号在 Web 调本地类别模型仍扣费，在桌面调用本机该类模型不扣费；桌面调云端模型实时扣费且生成记录关联原请求；断网不能绕过云端权益。管理员本地版不出现云端账号与付费入口，全部配置都只写入本机。

## 第四阶段：本地数据与可选同步

- 项目、Canvas 节点、创作记录、素材、短剧、生成任务与 Provider 账号写入本地持久库和本地媒体目录；桌面端使用与 Web 相同的任务状态机、引用计数与删除保护，断电重启后恢复轮询。平台公开作品、公告、公共 Skill/提示词可以缓存带 ETag 和更新时间的只读快照；后台配置数据按用户设定频率拉取，登录/积分/支付/模型调用始终实时。
- 本地配置同步默认关闭。用户显式启用时，本机对代理凭据、Cookie、Provider 密钥先用独立用户同步密钥加密，云端只存密文、版本、设备与更新时间；新设备解密需要用户授权，不把云端管理员后台密钥混入个人配置。字段冲突用 revision/ETag 和逐条选择，不做静默 last-write-wins；删除使用墓碑与保留期。
- 默认免费云存储 `1 GiB`，管理员可调整默认额度，超过默认额度必须购买单独存储套餐。云端 OSS 对象按 `tenant/userId` 隔离，上传申请和完成登记均验证身份、对象大小与配额；临时未完成分片按租约回收。用户管理展示已用、预留、可用、套餐有效期与按项目/素材/主动备份分解统计。项目备份与跨设备恢复属于同一额度；本地素材不上传就不计费。服务端以对象清单及去重存储键统计，不能相信客户端上报的字节数。
- 支付成功/退款/到期由云端变更存储权益；到期超额先停止新上传，给恢复/导出宽限期，不因套餐到期立即删除已存作品。同步频率只影响只读快照/配置，不影响购买与配额强校验。

验收：1 GiB 边界、多文件同时上传、取消/失败分片、重复备份、删除释放容量、套餐过期、两设备同一配置冲突、跨用户越权、加密密钥丢失与恢复均有服务端测试和干净机器端到端测试。

## 质量门禁和实际运行记录

- 每次 Web 改动执行 `cd web && pnpm test && pnpm lint && pnpm typecheck && pnpm build`，然后 `pnpm start` 重启生产运行时，回归 Web 原有登录、画布、后台与计费。
- 桌面执行 `cd apps/desktop && pnpm test`；管理员无账号首次启动、重启后项目持久化、Provider 数据/端口与 Web 隔离、双开拦截、非法外链和 Web 拒绝引导逐项验证。
- 商用版必须在云端联调环境验证登录、实时计费、云端生成、同步及 OSS；管理员版需验证无需云端服务可打开项目和本地配置。生成视频还需逐模型/比例/时长验证最终媒体而非只看任务受理。
- 当前阶段实测：管理员本地运行接口 `200`、免登录引导 `303`、健康接口 `200`；Electron 窗口的 Canvas 项目页与后台模型渠道页已通过 `capturePage` 截图复核，管理员页无用户与积分分区；实际创建一个画布项目，完全关闭并重启桌面进程后读到原项目，随后清理测试项目；商用入口无本地登录表单。打包预检按预期拒绝缺失的冻结 Provider 文件。以上不能替代无依赖安装包与商用联调验收。
- Web 首页在 `1440/390/430px` 的独立无账号浏览器回归中均没有页面横向溢出；现有 Web 生产运行时健康接口 `200`、桌面专用运行接口 `404`。完整 Playwright Canvas/Home 矩阵曾因复用已有 `.e2e-data` 使安装前置断言失败；改用隔离数据重跑时发现测试启动脚本仍预热真实 Gemini 账号，随即终止回归、恢复原测试数据，并单独重启 Web。测试夹具需先隔离所有上游账号及固定 Sidecar 端口，再安全完成全矩阵。
- Web 的 Dola 账号管理已加入隔离的 Camoufox 有头测试：新实例、新空白上下文只注入选定账号 Cookie；直连、任意已启用通用节点或 Dola 当前绑定的魔法/链式出口可用于本次测试，管理员可远程点击、输入、滚动、刷新画面和主动结束，也能回到仍在运行的会话。结束时明确选择“不保存”或“检测登录并保存”：只在 Dola 启动协议确认登录有效时，按原账号凭据版本原子回写浏览器最新 Cookie，版本已被其他操作更新则拒绝覆盖；协议结果不明确时再以浏览器真实启动结果核验，仍未确认则保留窗口与旧 Cookie。管理员须在关闭原生浏览器前从后台选择保存；直接关闭原生窗口可能使最新 Cookie 无法读取，后台对此有明确提示。该功能不改变已有 Web 生成路由和桌面版本的计费边界；桌面本地版使用同一 Provider 接口。
- macOS arm64 管理员版首次打包暴露空的 GPTAPI 工作目录被打包器省略，导致进程启动 `ENOENT`；现随包加入对应上游许可证和声明文件并回归。执行 `DREAMYO_DESKTOP_UNSIGNED_TEST=1 pnpm pack:admin:mac` 已产出本机测试用 DMG/ZIP，打包产物自身在 `PATH=/usr/bin:/bin` 下启动通过：管理员免登录 Canvas、账务路由 403、上游配置页及 Dola 账号管理页正常挂载，关闭后无残留 Provider 进程。本机的非正式签名尝试因签 Sharp 原生模块返回 `errSecInternalComponent`，正式分发须另配有效开发者证书及公证，未签名包不可作为商业交付。
