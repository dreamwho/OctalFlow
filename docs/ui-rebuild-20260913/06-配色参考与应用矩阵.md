## 3. 渐变和密度规则

- 品牌横幅/背景：蓝位于左下与左侧，青/薄荷为中部衔接，淡紫在右，冰白在上；不要改成浓紫到电蓝的双色条。各颜色之间连续过渡，不画硬分区。
- B01按钮：保留新图的真实局部色域，尤其中央青/薄荷与右侧淡紫；不是仅将旧按钮紫色改淡。源图自带高光与透明留白，小尺寸派生时只调整外部装饰强度，不拉伸字形和星形。
- 输入、表格、正文区：浅色白/冷白，深色深蓝灰；品牌色放在focus、细边框、选择态、少量标题与操作上。可读性靠独立语义值，不能把整页亮青背景配白字。
- 图标：工具栏仍为单色currentColor；C01不授权恢复彩色PNG混排。真实模型Logo、内容图、用户头像不染色。
- 动效：只在已分离的装饰背景层轻动；保持清晰图形边界和锐利文字。柔和颜色过渡不等于整页运行时blur或蒙灰。
- C01中的细曲线如需要采用，只放于大块品牌留白，并使用已有合法素材或生成的独立背景，不手绘仿制参考线稿，不覆盖表单/Canvas媒体/后台表格。它不是必加的功能元素。
- 通常每个独立操作区保留一个主要渐变动作，其余次操作使用清晰中性色；生成配置的主按钮可按B01整行呈现，密集后台保存按钮用可读操作蓝，不套大型发光插画。

## 5. 状态与深色主题

|状态|浅色|深色|
|---|---|---|
|默认|白/冷白面板+深中性正文|深蓝灰面板+浅正文|
|hover|浅蓝青表面，描边略增强|同色相低透明青蓝底，文字变清晰|
|selected|浅蓝青底+可读深蓝字+细描边|低透明青蓝底+冰青浅字|
|focus|#3853D8清晰聚焦边/光标|#94E6ED聚焦边/光标|
|disabled|低饱和蓝灰，内容仍可辨，关闭光晕|深蓝灰+灰蓝字，关闭光晕|
|loading/running|原真实状态+单个图标，颜色同按钮家族|同色相，不新增白亮遮罩|
|success|绿色/薄荷语义浅底，深绿可读字|低透明绿底+浅绿字|
|warning/error|维持黄色/红色语义，不能改成品牌渐变|同语义低透明底与可读前景|

C01只提供浅色视觉参考，深色是保持同色相关系的设计派生，不宣称有独立深色原稿。深色不能简单反相C01，也不能把浅底Logo或按钮矩形背景带进去。
