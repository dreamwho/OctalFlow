# Canvas 模型选择、Agent 与节点参数弹层深化计划

执行日期：2026-09-16  
适用范围：Canvas 画布节点提示词面板中的模型选择、Agent 抽屉以及图片/视频/音频参数弹层。本卡只记录上传设计板对画布端的视觉验收目标，不改变上游模型目录、任务协议或外部服务授权边界。

## 设计依据与边界

- 模型选择浅色/深色：`全新UI设计/选中/模型选择弹出层深化设计板*.png`。
- Agent 抽屉：`全新UI设计/选中/agent设计.png`。
- 音频、图片、视频节点参数：对应 `全新UI设计/选中/音频模型参数弹出层深化设计板*.png`、`图片模型参数弹出层深化设计板*.png`、`视频模型参数弹出层深化设计板*.png`。

## 目标状态

1. 模型选择器从底部工具入口打开，保留真实能力过滤和当前值；弹层提供搜索、最近使用、厂商分组、选中/悬停/不可用状态，并在窄屏内可滚动。
2. Agent 抽屉保持右侧同层协作面板和真实任务流，补齐 Beta 标识、结果卡片的层级以及浅深主题可读状态；不改变会话、SSE、暂停、取消、重试和结果定位协议。
3. 图片、视频、音频参数弹层统一使用标题、说明、类型图标、内容滚动区、底部摘要和应用动作；参数仍通过现有节点配置保存，移动端按 `visualViewport` 计算边界。
4. 任何一个弹层关闭后触发器恢复中性状态，选中值通过文案或摘要表达；不使用固定假模型、假任务或付费外部调用完成视觉验收。
