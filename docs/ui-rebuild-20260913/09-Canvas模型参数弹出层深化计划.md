# Canvas 模型参数弹出层深化计划

执行日期：2026-09-16  
适用范围：Canvas 画布节点提示词面板中的图片、视频、音频参数入口。首页和 `/create` 的参数弹层不在本卡修改范围。

## 视觉真值

- 图片浅色/深色：`全新UI设计/选中/图片模型参数弹出层深化设计板*.png`
- 视频浅色/深色：`全新UI设计/选中/视频模型参数弹出层深化设计板*.png`
- 音频浅色/深色：`全新UI设计/选中/音频模型参数弹出层深化设计板*.png`
- 冻结副本与 SHA256：`evidence/20260916-canvas-parameter-popovers/reference/`

设计稿只定义视觉层级、密度、状态和交互呈现；实际字段、枚举、模型能力与提交值以当前项目协议和渠道能力为准，不新增上游不支持的选项。

## 当前问题

1. 图片和视频沿用通用小弹层，没有标题、说明、底部参数汇总和明确的应用动作，信息密度与设计稿差距明显。
2. 当前面板宽度约 360px，桌面比例、画质、数量被压缩；移动端虽能放入视口，但标题、分组和滚动边界不清晰。
3. 视频参考方式、比例、清晰度、时长、声音和水印缺少统一的分组层级。
4. 音频弹层复用宽面板，但标题、音色、滑块、情感和底部状态栏没有形成设计稿中的完整结构。
5. 三类弹层的浅深主题边界、选中态、悬停态和底部操作区不一致。

## 实施任务卡

### P01 共用 Canvas 弹层框架

- 为通用生成偏好组件增加仅由 Canvas 节点启用的视觉变体，保持 `/create` 和其他调用点默认表现不变。
- 桌面宽度以 500–540px 为目标；移动端为 `viewport - 24px`，由 `visualViewport` 计算可用高度并在内容区滚动。
- 增加图标、标题、说明、关闭按钮、分组内容、粘性底部摘要和“应用”按钮。
- 参数仍写入现有配置；“应用”负责确认当前值、关闭弹层并让触发器摘要立即反映配置。

### P02 图片参数

- 标题“图片生成参数”，说明“设置生成图片的比例、画质与数量”。
- 比例按真实渠道可用选项渲染为图形化网格；保留 GPT API 固定尺寸、Dreamina 能力限制和精确自定义宽高规则。
- 画质、数量、自定义数量保持当前真实契约；选中态采用蓝青渐变细描边和柔和底色。
- 底栏显示 `比例 · 画质 · 数量`，应用后关闭。

### P03 视频参数

- 标题“视频生成参数”，说明“设置参考方式、比例、清晰度、时长与声音选项”。
- 保留普通参考、首帧、首尾帧的真实引用与互斥校验；帧选择只使用当前连接的真实图片。
- 比例、自定义尺寸、清晰度、自定义清晰度、时长、生成声音和水印继续受当前模型能力约束。
- 底栏显示 `参考方式 · 比例 · 清晰度 · 时长`，应用后关闭。

### P04 音频参数

- 标题“音频模型参数设置”，说明随当前音频模式保持真实能力。
- 文转语音展示音色、语速、音量、音高、情感等现有字段；音乐、音色复刻和音色设计继续使用当前真实分支，不伪造设计稿字段。
- 滑块、数值、选择列表和情感选项形成一致分组；保留现有音色 API、音色创建 Modal 与错误处理。
- 底栏显示功能类型、模型/音色摘要和当前生成数量；应用关闭弹层。

### P05 自动化回归

- 为 Canvas 三类参数弹层增加组件或 E2E 回归：入口可访问名、面板标题、真实选项更新、应用关闭、自定义输入、视频引用模式、音频滑块/情感。
- 执行相关 Vitest、TypeScript、生产 build；Playwright 必须被 `--list` 发现。

### P06 真实浏览器设计验收

- 生产构建启动后，在隔离 Canvas fixture 中验证图片、视频、音频三类弹层。
- 视口：1440×900、430×932、390×844；主题：浅色、深色。
- 每个状态记录 route/theme/viewport/state/zoom/buildId、截图、面板几何、视口溢出、可点击命中和关键颜色。
- 不调用付费生成渠道；只验证参数选择、持久化回填和弹层行为。

## 验收条件

- 三类弹层均与六张设计稿的层级、圆角、玻璃卡片、蓝青紫选中态和深色对比一致。
- 所有文字、图标、输入值、滑块和生成按钮在浅深主题可读。
- 390/430px 下弹层完全位于可视区，内部可滚动，底部应用按钮可通过正常语义点击操作。
- 不影响 `/create` 通用参数弹层；不改变任何上游模型协议、参数优先级或付费生成行为。
- 自动化、类型检查、生产构建和真实浏览器验收均有当前 build 证据后才能标记通过。
