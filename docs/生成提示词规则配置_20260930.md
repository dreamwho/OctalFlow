# 生成提示词规则配置与验收

## 使用方法

打开「管理后台 → 系统设置 → 生成控制 → 生成提示词优化规则」。

- 开启：应用配置内容。
- 关闭或内容为空：不应用该项规则，仍提交真实参考素材。
- 修改后点击「保存系统设置」，对之后提交的任务生效；已提交任务继续按原请求执行。
- 原有自动规则默认开启，内容沿用既有规则。四种通用规则默认关闭、内容为空。
- 关闭示例中的双语人物前缀，关闭「图片参考素材约束」；Sub2API 的图片编辑另关闭「Sub2API 图片编辑约束」。
- 参考素材规则和通用规则相互独立。MiniMax H3 的格式包装也独立配置，关闭参考素材规则后如需完全使用原文，同时关闭对应 H3 包装。
- 音频规则写入渠道 `instructions`，不进入朗读正文或歌词；需要上游及其请求模板支持该字段。

## 审查结果

| 自动处理位置 | 配置项 | 生效条件 |
| --- | --- | --- |
| 通用图片参考前缀 | 图片参考素材约束 | 原有 OpenAI multipart/JSON/Responses、Gemini、GlobalAiOpc 参考图提示词链路 |
| Sub2API 图片编辑专用前缀 | Sub2API 图片编辑约束 | Sub2API JSON 图片编辑 |
| 全景输出约束 | 全景节点输出约束 | 画布全景节点提交及重试；改为服务端应用，前端不再写入执行草稿 |
| 视频素材保持约束 | 视频参考素材约束 | 普通参考图或视频 |
| 首帧连续性约束 | 视频首帧约束 | 显式首帧角色 |
| 首尾帧连续性约束 | 视频首尾帧约束 | 显式尾帧角色 |
| H3 自动格式包装 | MiniMax H3 文生 / 首尾帧包装 | H3 文生、图生或首尾帧模式 |
| H3 多模态参考包装 | MiniMax H3 多模态参考包装 | H3 普通多模态参考模式 |
| H3 结构化绑定说明 | MiniMax H3 素材绑定说明 | H3 基础模板或已有结构化提示词 |
| 图片、视频、文本、音频通用文本 | 各自通用优化规则 | 默认关闭，需要管理员自行配置 |

普通文本和音频节点没有发现同类默认人物保持前缀。上游要求的协议字段、参考素材角色校验继续执行。用户主动选择的 Skill、相机、运镜、角度调整、室内设计参数及默认模型规划保持原有功能契约。

模板支持界面列出的变量，其他普通文字按管理员输入保存。H3 模板可使用 `{{prompt}}`；遗漏该变量时仍会在末尾保留原始请求。

配置存放在现有 `generationDefaults.promptRules` JSON 内，沿用文件与 PostgreSQL 设置持久化，不增加数据表。普通用户 Session 不公开这些内部模板，无上游管理职责的管理员也不接收模板。
