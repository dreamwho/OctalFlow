# 2026-10-21 生成任务与 GPTAPI 管理更新验收

## 功能与根因

- GPTAPI 只有普通账号删除入口，缺少按已确认状态批量清理的入口。增加数量预览和二次确认，只清理已禁用账号，或凭据检查已确认失效的异常账号；临时网络错误、超时、限流及未确认异常保留。原生清理使用账号锁、权威快照与现有持久化删除，不调用真实上游检查。
- 工作台参考图横向列表把添加入口挤出可见区域。添加入口改为左侧固定、具有不透明背景的独立按钮；参考缩略图仍可横向滚动。
- 结果菜单将重新生成直接绑定任务提交，并限制活动状态操作。改为恢复原公开提示词、稳定参考素材、实际模型与参数到左侧草稿；用户修改并手动生成后才提交。成功、失败、待确认、准备中和生成中均开放菜单。删除先取消对应归属任务，再删除记录或结果；创建、上游提交和迟到回写均检查删除竞态。
- 原逻辑模型没有对应备用模型配置。新增同能力备用逻辑模型，拒绝无效或循环绑定；工作台与 Canvas 在明确失败且可安全重试后，查询当前角色可用的备用模型并请求用户确认，单次操作最多切换一次。超时、连接/查询异常、结果待确认、权限与并发限制不会自动跨模型重建。

- 本轮尺寸补充：后台尺寸字段原先未进入公开目录和前端选项，英文逗号输入被即时去空处理吞掉。现在保留原始编辑文本，公开尺寸能力白名单，工作台/Canvas/Canvas Agent 使用当前绑定的配置选项，像素尺寸保持原值提交。操作方法与文档默认值边界见 `图片尺寸配置说明.md`。
