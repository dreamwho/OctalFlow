# GeminiAIStudio 动态模型目录与 Nano Banana 2.1

已实现获取当前授权 AI Studio 账号的模型目录、手动添加文本/图片模型 ID、逐项实测及显式保存到渠道。Nano Banana 2.1 已作为图片预置加入。与现有文本/图片协议一致的新模型无需再次修改代码；新协议仍需单独适配。

## 使用流程

后台 → GeminiAIStudio → Gemini AI Studio 渠道与模型：点击“获取账号模型”，或“手动添加模型”填写 ID、能力与可选目录名称；点击模型行“测试模型”会预选 ID，再点击“开始实测”才生成。最后勾选模型并点击“保存所选模型”。登记不会自动调用模型，也不会自动开启渠道绑定。
