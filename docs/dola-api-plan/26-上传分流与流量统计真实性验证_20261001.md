## 精度与连接验证

- HTTP、HTTPS、SOCKS5 及 HTTP → SOCKS5 链式代理均使用随机端口的真实 TCP 服务，分别在代理服务端和 DOLA 计量出口独立计数；并发短连接的上行、下行偏差均为 0 B，包括代理握手及 TLS 数据。
- 本地计量中转采用每次进程随机凭据并禁用按 IP 缓存鉴权；授权后同一 IP 的无凭据客户端仍返回 407，未增加上游计数。真实 Camoufox 浏览器通过认证连接的本地页面验证通过。
- 时区、开始边界、结束边界、端口筛选、行合计与总计一致性、重复读取不重复计量、关闭后重新打开数据库保留数据、失败响应均通过测试。
- 两个 917,504 B 的素材数据夹具通过本地真实 TLS 源站与所选 HTTP 代理完成下载、Apply、上传、Commit 共 8 个请求；复用一个 HTTPX 客户端和一条源站 TLS 连接。设置为不可用的账号提交代理未被访问。
- 站内签名参考素材沿用内部直连读取；普通外部参考图的下载已改为遵循上传出口，不再继承账号提交代理。

计量口径是 **Provider 出口 TCP 流字节**：写入的字节按写入时间保存，接收的字节按到达时间保存，UTC 持久化，时间窗为 `[开始,结束)`。记录配置中的代理主机与端口，直连记端口 0；不会保存代理密码、Cookie 或图片二进制。包含浏览器、登录/查询协议、来源素材、ImageX 传输；不含 TCP/IP 包头、重传、DNS UDP、Provider 外的结果下载及链式代理后续跳点。链式入口只计一次，不虚构后续跳点的供应商计费数据。因此与供应商账单可能不同。
