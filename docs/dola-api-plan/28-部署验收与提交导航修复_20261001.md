## 后续本地修复

提交代码此前在页面隔离环境中反复读取 DOM 以等待 SSE，导航会销毁执行上下文。现在捕获浏览器原生 SDK 加签后的最终 POST、中止浏览器原始传输，再通过同一提交代理实际发送一次；SSE 在 Python HTTPX 中读取，脱离页面文档生命周期。沿用原有 70 秒整体预算和 60 秒请求超时，没有新增提交重试或固定延时。

保留实际浏览器签名、设备身份、Cookie、请求体和 SDK 请求头；代理认证头只用于客户端自身代理连接，不复制到源站；内容编码由 HTTPX 正常协商。收到 `SSE_REPLY_END` 即结束读取，流中断前收到的 ACK/会话 ID 不丢失。发送后状态不确定时保留原任务和 `local_conversation_id`，按该 ID 查询关联会话，不重复创建生成请求；连接建立前失败继续明确报错。Camoufox 隔离环境通过字符串 DOM 事件接收主页面签名错误，避免签名失败变成无意义的超时。
