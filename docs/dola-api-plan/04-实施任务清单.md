> **v1.7详细开发计划，用户已确认并进入实施。** Cookie初始化的Camoufox原生页面会话是正式提交主传输；独立HTTP和区域节点结果只作为测试证据。代理统一接入现有通用代理管理，Dola 保存 `node:<id>`/`group:<id>` 引用，不再有台湾专用修订或环境变量。单文件多账号/多文件单账号的统一导入任务与证据见[16](16-105账号Cookie批量导入与直协议复测.md)。

> 后台公开导入固定为Cookie Header粘贴/文本文件，不再公开JSON/storageState。T02-V继续作为异常恢复能力；T10复用现有 proxy view/resolve-url 解析通用出口并保持凭据边界。正式提交只走Camoufox页面，独立HTTP只作诊断/失败对照；历史台湾节点仅保留在实测证据中；当前ACK Case没有持续查询最终媒体，完整Provider闭环仍待实施。
当前为 **应用实施中**。T03/T06/T08/T09/T11 已有首版代码与离线测试；T02真实页面选择器、T04额度刷新与原子预留、T05持久任务闭环、T07参考图上传、T10现有代理服务联合、T12/T13挑战恢复与派生节点、T14/T15仍须按真实Provider和部署环境验收。每张任务卡完成时填写本文件末尾的交接记录。

## 1. 依赖与阶段出口

```text
T00 基线
 └─ T01 当前协议证据
     └─ T02 Provider 最小纵向验证
         ├─ T03 数据/账号 ─ T04 调度 ─ T05 持久视频链路

T05—T13 ─ T14 完整验收 ─ T15 部署与交付
```

图中是依赖关系，不要求启动多个 Agent。单 Agent 按顺序完成即可。若用户另行授权并行，公共 schema、protocol registry、代理联合类型和任务状态修改须由一个负责人合并，避免多处各加一半。

计划前原生基线出口已完成，见10；实施阶段 A 的出口是导入账号后在隔离Provider中可复现的视频闭环。15/30秒编译与真实媒体验收由T06/T09/T14继续完成；仅做好账号页不能进入“功能已完成”状态。当前代码已先落地可审查的合同、配置、导入、管理页和离线夹具；真实页面选择器、媒体闭环和后处理能力必须取得对应实测证据后才可勾选完成。

### T02 — 隔离 Provider 最小纵向验证

依赖：T01。新增：

- `services/dola-api/pyproject.toml` 与锁文件、`Dockerfile`、`README.md`、`NOTICE.md`。
- `services/dola-api/src/dola_api/{app,contracts,session,protocol,transport,sse}.py`。
- `services/dola-api/tests/`，按真实样本建立脱敏 fixture。

步骤：

1. FastAPI 只暴露 02 §7.1 最小内部路由；服务 key 从环境读取，无固定 fallback。
2. 账号授权数据仅由服务端传入；从加密Cookie Header建立按`accountId+credentialVersion+proxyTarget/proxyUrl`隔离的Camoufox持久context，真实页面初始化后提交已验证参数。
3. 把请求编译、SSE 解析、查询映射与 Browser 操作分开，避免业务代码塞进巨型 page.evaluate 字符串。
4. 以15通过Case为开发基线，在目标Linux复现Cookie→全新context→登录→上传→Fast5秒ACK→精确查询→媒体下载；桌面已登录和本机ACK不能代替目标环境媒体闭环。
5. 原请求失联只能查询同一任务；实现 submitted/unknown 返回，不添加任意生成重试循环。
6. 主transport固定`camoufox-page`；发送前CAS `dispatch_started`，页面只点击一次并捕获本次`/chat/completion`。真实SSE_ACK才进入accepted；verify/slide进入verification_required；无ACK/断线进入submission_unknown；代理导航区域限制进入`proxy_region_blocked`且不得点击创建。独立HTTP不作普通提交或自动回退，代理不因滑块自动更换。只有取得真实媒体才判完整Provider生成通过。

测试：内部未授权请求 401；无账号/失效账号错误；独立Provider真实生成/恢复链路（优先与后续获授权的未测组合合并）；15/30参数编译按11，媒体验收归T14；SSE 分片/终态/误文本测试；HTTP200+STREAM_ERROR+SSE_REPLY_END无ACK必须失败/待验证，错误extra.ack不能当任务ID。禁止启动参考项目远程安装、自更新或 memory reclaim 脚本。

出口：独立服务可在项目环境重现同一个能力契约；还不能宣称完整后台/Canvas 已接入。

```text
任务编号 / 状态：Txx / 待办、进行中、待验证、完成、阻塞
```
