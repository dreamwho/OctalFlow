## 3. 确定的实施架构与待验证边界

采用项目已有的结构：**Next.js 管理页及业务服务 + Cookie初始化的Camoufox隔离Provider + 已有持久生成任务/Worker + URL无水印提取**；CPU修复为另行明确启用的可选方案。

- Next.js 负责权限、账号元信息及加密凭证、配额记录、账号调度、API 密钥、日志、模型路由、任务与媒体归属。
- Dola Provider 负责真实 Dola Web 会话、上传、提交、SSE、查询与结果读取。正式transport固定为Camoufox原生页面请求；页面内部产生的 HTTP 请求由浏览器正常发送，产品不使用无浏览器独立HTTP作为提交器。独立HTTP仅作为研究/失败对照保存，不能由任务运行时切换或自动回退。代理统一使用现有通用代理管理的 `node:<id>` 或 `group:<id>` 引用，直连默认；历史台湾节点仅是一次测试样本，不提供专用环境变量或产品分支。
- 去水印首选已验证的第一方URL提取；自动模式在视频落盘前解析，手动模式从 Canvas 右键生成派生节点并保留原视频。不静默切换到有损局部修复，不宣传字节无损。详见07。
- 后台沿用 Google AI Studio 的视觉结构，增加 GPTAPI 已有的统计 Tab；按本项目 React/Ant Design 写法实现，不嵌入参考项目的管理页。
- 不整包搬入 Electron、AstrBot、浏览器扩展、自动安装/自更新脚本；只采用经验证且可使用的协议事实、算法思路与必要代码。
