# 二、名称解释：把“梦”从睡眠转向创造

## 2.1 从用户原始想法出发

用户提出的方向是：唤醒、沉浸梦幻世界、将脑海的幻想构想出来。

建议整理为三个连贯层次：

**唤醒想象。** 唤醒的不是正在睡觉的人，而是还没有被表达出来的画面、故事与构想。

**沉浸创作。** 沉浸不是逃离现实，而是让注意力停留在创作本身，在同一个空间中持续展开想法。

**让作品出现。** 最终价值不是停留在梦境的氛围里，而是把原本只在脑海中的东西，转化为可看见、可继续完善的内容。

因此，品牌不是“带你去做梦”，而是：

> **给想象一个可以被展开、被看见、被做出来的地方。**

## 2.2 dream + yo 的品牌化解释

**dream**：承接梦境、幻想与未被表达的构想。在 dreamyo 的品牌语境里，它不只指睡眠中的梦，也指创作者想看见、却尚未创造出来的世界。

**yo**：将其定义为品牌自创的轻快呼唤与行动感，像是对灵感说“嘿，该让你出现了”。它为名字增加亲近感，让 dream 不只停留在内心，而开始进入创作。

以上是品牌叙事，不是词源考据。不要宣传 dreamyo 来自某个古老语言、天文专名，或把 yo 硬说成未经依据的英文缩写。

## 2.3 标准命名说明

> dreamyo 围绕梦境与创作而命名。dream 承载尚未被表达的幻想，yo 则被赋予轻快的唤醒意味。我们希望把一个原本只存在于脑海的想法，带进可以持续展开的创作空间，让它逐渐拥有画面、动态与完整的表达。

# 三、品牌定位与价值

## 3.1 一句话定位

> **dreamyo 是一个连接图像、视频模型与创作智能体的 AI 创作空间，让用户在无限画布中，把构想推进为作品。**

情感层表达“想象被看见”，产品层说明“无限画布与 AI 创作”，技术层再解释“图像模型、视频模型和 Agent”。三层不要颠倒：面向创作者先讲作品，技术说明中再讲模型。

## 3.2 建议优先服务的人群

| 建议人群 | 主要需求 | 推荐表达 |
|---|---|---|
| 视觉设计师与创意工作者 | 探索画面方向、形成视觉内容 | 把脑海里的视觉，带到画布上 |
| 短视频与内容创作者 | 从想法走向图像、视频和成片 | 从一个构想，推进到一部作品 |
| 品牌内容与新媒体团队 | 组织内容创作，提高创意落地的连贯性 | 让创意留在同一个空间里继续生长 |

以上为建议市场定位，不代表已验证的客户画像。首批对外作品案例可涵盖空间视觉、产品视觉和叙事短片，不必把品牌限定为装修设计或某一种行业工具。

## 3.3 三项核心价值

**想象可以开始。** 不要求用户先完成一份完善方案，再获得创作入口。

**创作可以延展。** 无限画布提供组织与展开内容的空间，而不只是一张单次生成的结果页。

**作品由你定义。** Agent 是帮助推进任务的创作助手，创作者保留方向、选择与结果判断。

这是一套体验目标，不代表任何构想都能一次生成到位。

## 3.4 使命、愿景与性格

**使命：**让脑海中的构想，拥有成为作品的可能。

**愿景：**成为创作者从灵感开始，到作品成形的常用空间。

**品牌性格：**有想象力，但不玄虚；有科技感，但不冷硬；亲近友好，但不过度幼态；强调自由，也尊重创作者的控制感。

**建议避免的定位：**万能造梦机、元宇宙入口、梦境解析、AI 算命、无所不能的内容工厂。这些表达会使产品定位偏离真实创作任务。

# 八、视觉设计方向

本节为设计简报，不是已经生成或确认的 Logo 图稿。

## 8.1 总方向：梦的入口，创作的窗口

建议关键词：流动、轻盈、留白、温润、清晰、未来感。

视觉表达应传达“想象正在成形”，而不是“睡眠、疗愈、算命、游戏入口”。不采用月亮、云朵、四角星、行星轨道的堆叠，不延续星轨 Logo 中现成的星核和轨道节点。

## 8.2 Wordmark

以全小写 dreamyo 为核心，使用具有亲和力但不过度圆润的现代无衬线字形。

建议在 d 或 y 上建立一个可延展的独特细节，但保持整体单词阅读顺畅。dream 与 yo 使用一致的排版逻辑，不把后半段做成夸张口号或儿童化贴纸。

## 8.3 图形标识概念

**方向名称：梦之窗。**

由一条柔和、具有方向的带状曲线形成半开放的不规则轮廓。局部负形隐含小写 d 的关系，中央留白既像一扇入口，也像尚待填入内容的画布。

外形代表想象尚未被固定的状态；内部清晰的空间代表创作将其逐步组织。用一个连续的视觉结构表达两层意义，不再在不规则底板里塞入多个独立小图标。

图形是独立设计方向，不照搬参考产品的具体轮廓。定稿后建立一个矢量母版，所有应用与尺寸从同一母版导出。

## 8.4 建议色彩

| 用途 | 名称 | 色值 |
|---|---|---|
| 主品牌色 | 梦境紫 | #7856FF |
| 辅助品牌色 | 清透蓝 | #5B8CFF |
| 轻背景 | 雾紫 | #F1EDFF |
| 画布基础色 | 画布白 | #F8F9FD |
| 正文字色 | 墨紫黑 | #17162B |
| 小面积点缀 | 灵感薄荷 | #6DE3CE |

主渐变建议为 #7856FF → #5B8CFF。色值为本方案建议，不是已确认的现有 VI。

如与星轨采用同一产品家族的设计体系，可让星轨偏冷蓝与秩序感，dreamyo 偏紫与流动感。通过字体、间距与组件建立家族联系，不复制同一个 Logo。

## 8.5 不同场景的视觉强度

**官网与发布物料：**可以使用梦幻光感、柔和流动形态和真实作品，让品牌具有情绪。

**创作工作区：**以明亮、中性、低干扰为主，画布边缘与操作状态清晰，不用大面积模糊玻璃层覆盖作品。

**图标与小尺寸场景：**以干净轮廓和明确负形为主，实际测试 16、24、32 像素的识别效果；不要只在大图上判断是否好看。

**动效：**表达从模糊到清晰、从念头到作品的过程；核心图形不持续变形，不影响品牌识别。工作界面尊重减少动态的用户偏好。

不写：

“无限”描述画布的创作组织方式，不描述免费额度、无上限算力或不限次数调用。
